# Free interactive learning tools for Linux system administration

Scope: free visualisers, explainers, playgrounds, calculators and simulators for Linux sysadmin, the same kind of tool as Protocol Explorer. Reader: an on-prem Ubuntu DevOps engineer moving to cloud. Every domain in `known_domains.txt` was skipped. All tools below were opened on **2026-11-09**, with WebFetch (static pages) or the built-in browser (JavaScript apps, read with get_page_text). Nothing was signed into, submitted, downloaded or run. The one exception: one explainer was opened with a sample command in its URL (`mankier.com/explain?q=find . -mtime +7 -delete`), which contains no personal data. Where only a search snippet was seen, it says so.

Levels: L0 = fresher, L1 = junior, L2 = mid-level, L3 = senior, L4 = lead/SRE (the handbook milestones).

## Q1. Which tools are verified, and how do they rank?

### Takeaway
There are 30 verified tools, ranked below. The strongest picks for the handbook are explainshell, crontab.guru, regex101, the official jq playground, linuxatemyram, the tldr PWA, speedscope, the Linuxize systemd generator, the incoherency.co.uk systemd timer builder, eBPF.party and JSLinux/v86. The ranking weighs teaching value, fit to the handbook's topics and privacy. Most generators and calculators run in the browser. The explainers, savers, eBPF.party and ssh-audit send what you type to a server.

### Inferences
- explainshell, mankier, regex101 (on save), RegExr (on save), ssh-audit, eBPF.party and DistroSea all send input to a server. The handbook should tell readers to paste only sanitised commands and log lines (no tokens, internal hostnames or customer IPs). The local-only tools are play.jqlang.org, speedscope, Perfetto, Firefox Profiler (until shared), the Linuxize generator, the hidekazu chmod/umask calculator, JSLinux and v86. Those are safe for real JSON, profiles and permissions.
- Cloud bridge: JMESPath is the query language behind `aws ... --query` (background knowledge; not re-verified this session because aws.amazon.com is a known domain). This makes jmespath.org the natural next step after jq for this reader. Cronuru's EventBridge and Kubernetes CronJob conversion does the same job for scheduling.
- ssh-audit.com can't reach typical on-prem internal hosts. The same project's CLI does, but it is install-only and hosted on GitHub.

### Gaps
- Speedscope's README does not mention collapsed-stack (Brendan Gregg `.folded`) input; I did not verify it.
- Free, no-sign-up status of regex101 and crontab.guru is inferred from the visible UI (no paywall on the core tool), not stated on their pages.
- The Systemd Timer Builder's author and date, and whether it previews the next run times, were not visible.

### Inferences
- For the L0→L1 study path, a sensible order is tldr → explainshell → chmod/umask calculator → crontab.guru → jq playground → regex101 (BRE/ERE mode). The L3–L4 perf path is speedscope/Firefox Profiler (open a `perf script` export), then Perfetto (ftrace), then eBPF.party.

### Gaps
- No tool maps cleanly to host-firewall, private-ca or secrets in this Linux sweep. Those were outside the brief and are likely covered by other researchers.

## Q3. What is uncovered, and what do roundups and awesome-lists add?

### Takeaway
No free browser tool was found for systemd OnCalendar *explanation* (as opposed to generation), sudoers/PAM/SELinux/AppArmor, load average, the boot process or LVM. Awesome-shell lists almost no browser tools. Hacker News Show HN (via the Algolia API) turned up only LinuxLabs and TUIs.

### Cited Findings
- **OnCalendar explainer:** search found no web tool. The canonical explainer is the CLI `systemd-analyze calendar`, which shows the normalised form and next elapse ([opensource.com](https://opensource.com/article/20/7/systemd-calendar-timespans)). The [Timer Builder](https://tools.incoherency.co.uk/systemd-timer-builder) generates but was not confirmed to explain or preview.
- **sudoers:** no interactive explainer found. The best plain-English guide is [Understanding sudoers(5) syntax](https://toroid.org/sudoers-syntax) (static article). The man page is browsable on [ManKier](https://www.mankier.com/5/sudoers).
- **SELinux / AppArmor / PAM:** no free browser playground found. Results were paid labs (Pluralsight) or flashcards ([search results incl. Pluralsight](https://www.pluralsight.com/labs/aws/resolving-selinux-issues)).
- **Load average / CPU:** no interactive simulator found; only articles, e.g. [site24x7 run-queue](https://www.site24x7.com/learn/linux/cpu-run-queue-length.html) and [Glances docs](https://glances.readthedocs.io/en/develop/aoa/load.html). Brendan Gregg's load-average article is on a known domain.
- **Boot process:** no interactive explorable found; [Bootvine](https://www.linuxlinks.com/bootvine-live-systemd-boot-shutdown-visualisation/) and Bootchart are local tools ([linuxlinks](https://www.linuxlinks.com/bootchart/)).
- **LVM:** no visualiser found. Red Hat's LVM-on-RAID calculator is on redhat.com (known domain) ([Red Hat Labs appendix](https://docs.redhat.com/en/documentation/Red_Hat_Enterprise_Linux/7/html/storage_administration_guide/appe-customer-portal-labs)).
- **bpftrace in the browser:** none found; [eBPF.party](https://ebpf.party/) is C/libbpf-style only.
- **awesome-shell:** almost no browser-based learning tools; mostly guides and CLIs ([awesome-shell README](https://raw.githubusercontent.com/alebcay/awesome-shell/master/README.md)).
